# 游戏更新

[简体中文](UPDATING.md) | [English](UPDATING.en.md) | [首页](../README.md)

## 下载和安装

安装包统一放在 [MEGA 下载文件夹](https://mega.nz/folder/PfIDSaSZ#ZcRokP34or9J0JofsIgrEA)。GitHub Releases 只发布版本说明和不含素材的文本源码，没有安装包附件。

1.2.0 及更早版本的旧更新器依赖 GitHub 附件，可能显示“新版安装包尚未上传”；请手动从上述文件夹获取当前版本。1.2.1起仍通过GitHub正式发布的标签检查更新，但“下载更新”改为打开MEGA文件夹，不再承诺在游戏内直接下载该文件夹中的APK。

Android请下载后覆盖安装，保留存档。iOS仍需自行重新签名IPA后安装。文件夹链接不提供单个安装包的大小、摘要或可直接下载的地址，因此不把它传给原生APK下载器。

## 检查更新

启动进入空闲主菜单约5秒后自动检查一次，也可使用 **设置 → NT:TE → 版本更新**。离线、超时或限流不阻止启动，战斗中不自动弹出提示。更新器逐段比较正式版本号，拒绝降级、草稿和预发布；只认可发布说明中的固定下载页，不打开任意外部地址。

## 发布策略

当前版本 **1.2.3**，内部构建91（Android versionCode 3000091，iOS build91）；下一修复版1.2.4、内部构建92。后续修复按0.0.1递增；1.0.4及后续1.0.x保留原NTTE内容。`GAME_BUILD`属于存档格式，不随发布修改。

每次同步游戏/更新器/平台版本并完成测试；源码上传前执行 `python tools/audit_source_only.py --index` 和 `--history`。不上传图片、音频、字体、运行库、安装包、签名或个人存档。发布同名正式标签，双语说明附上同一MEGA下载链接和第三方鸣谢。
