# NTTE＋Uncharted Frontier 2.0.2

- 修复极光天气读取背景色的报错，并减少 NTTE 区域天气兼容路径的重复处理。
- 统一风暴王冠的未解锁图标；修复宫殿移动方块的速度和碰墙后错误碎裂。
- 逐帧检查 259 帧录屏中的“随机角色→泡泡”路径；修复旧存档无效起始武器，并验证随机开局及死亡后重试。
- 修复 NTUF 统计／鸣谢排版；在自定义武器中增加独立 NTUF 栏目。
- 修复控制台 goto 中 NTTE／NTUF 区域名称的字体显示。
- 修复墙上生成的大苍蝇横向飞离、无法正常落地的问题。
